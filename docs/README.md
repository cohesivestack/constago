# Constago Docs (Starlight)

This folder contains the Constago documentation site built with Astro and Starlight.

## Prerequisites

- Node.js 22 or later

## Commands

From the `docs/` directory:

```bash
npm install
npm run dev
```

Check and build the site:

```bash
npm run check
npm run build
```

Preview the production build:

```bash
npm run preview
```
